    Try it with an agent
    From clicks to tool calls.
    The buttons demonstrate the behavior. Connect a client to let an agent discover and use it.
    
        
      
            
    1. Connect an MCP client.
      Choose Streamable HTTP and use the endpoint above. List tools, resources, and prompts. Try search_articles with {"query":"videos"}, then read a returned resource URI.
      2. 
            
    2. Open a WebMCP-capable browser.
      Enable WebMCP testing using Chrome's current setup instructions. Keep this page open and inspect its registered tools.
      3. 
            
    3. Ask the agent to search, then preview.
      Try “Use demo_find_articles to find videos.” Submit the populated form, then ask it to preview a returned article with demo_preview_article. Watch the page and activity log update.
      4. 
        
    
        
    Cloudflare's WebMCP bridge can also expose the server's search_articles tool in the browser. Resources and prompts remain available through the MCP endpoint.
