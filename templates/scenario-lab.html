One task, two ways through.

The standard links register scenario tools when your browser supports native WebMCP. Browser-only links disable this sample's tools while keeping the same fields, validation, and outcomes. Each reload starts a fresh run.

Booking availability is generated for the next 60 days. For repeatable comparisons, append ?date=2026-09-14 to fix the calendar's start date, or ?date=2026-09-14&webmcp=off for a paired browser-only run. The experiment controls on each sample export local timing, action counts, and completion status, without entered form values.

Enable native tools using Chrome's WebMCP setup instructions. The page shows whether registration succeeded. These samples do not measure model tokens or prove an efficiency gain by themselves.

The tax organizer is inspired by common client portals. It is not TaxDome, is not affiliated with TaxDome, and does not prepare or file a tax return.
